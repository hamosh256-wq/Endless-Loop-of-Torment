# 🎮 Endless Loop of Torment (ELTO)

**A 2D Dark Fantasy Action Platformer built with Godot Engine.**

## 🩸 About the Game

*Endless Loop of Torment* is a 2D action platformer set in a dark fantasy world. Play as a demon hunter, face dangerous enemies and powerful bosses, and fight your way through challenging levels using combat abilities and special powers.

The project was developed as a game development project using Godot Engine.

## ✨ Features

- ⚔️ **Action Combat** — Fight enemies using melee attacks and special abilities.
- 👹 **Enemy AI** — Enemies with combat and movement behaviors.
- 🔥 **Special Skills** — Use dark-themed powers and magical attacks.
- 💀 **Boss Battles** — Face powerful bosses throughout the adventure.
- 🪙 **Collectibles** — Collect coins and track your progress.
- ❤️ **Health System** — Manage your health while fighting enemies.
- 🎞️ **2D Animations** — Animated characters, enemies, and effects.
- 🌑 **Dark Fantasy Atmosphere** — Pixel-art-inspired visuals and a dark world.

## 🛠️ Built With

- **Godot Engine 4**
- **GDScript**
- **2D game development tools**

## 🚀 How to Run

1. Install [Godot Engine](https://godotengine.org/).
2. Clone or download this repository.
3. Open Godot Engine.
4. Import the project by selecting the `project.godot` file.
5. Open the project and press **F6** to run the current scene, or **F5** to run the main scene if configured.
